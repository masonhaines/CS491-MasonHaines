CMD:
dotnet new webapi --use-controllers -o CalendarApi

Beginning 

Once that command finishes, cd CalendarApi and open it in your editor. You'll see:

Program.cs — the entry point. Builds the app, registers services (DI container), configures the middleware pipeline, starts listening.
CalendarApi.csproj — project file: target framework, NuGet package references, build settings. This is your package.json equivalent.
appsettings.json / appsettings.Development.json — config values (connection strings, logging levels), environment-layered.
Properties/launchSettings.json — dev-time launch profiles: which port, which environment variable (ASPNETCORE_ENVIRONMENT) gets set when you hit run.
Controllers/WeatherForecastController.cs — the sample controller the template scaffolds so you have something to hit immediately.
obj/ and bin/ — build output, gitignored, don't touch.

-------------------------------Run it with dotnet run and confirm you get a URL back in the terminal and the sample endpoint responds.

Delete - Delete - Deleteds a resource
